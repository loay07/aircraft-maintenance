The problem

Turbofan engines degrade gradually over hundreds of flight cycles before failing. Waiting for a fault to appear means unplanned downtime; servicing on a fixed schedule wastes healthy engine life. Predictive maintenance estimates how many cycles remain before failure, directly from sensor readings, so maintenance can be scheduled exactly when it's needed.

Dataset

NASA C-MAPSS FD001 — simulated turbofan run-to-failure trajectories.

  • 100 engines to train, 100 held-out engines to test
  • One operating condition (sea level)
  • One fault mode (HPC degradation)
  • 21 sensors + 3 operational settings per cycle

Task

Each training engine runs from healthy to failure. Each test engine's series is cut short before failure — the model must predict cycles remaining using only the data observed so far, and is scored against NASA's official true RUL labels.

Model

XGBoost gradient-boosted trees, trained on 58 engineered features per cycle, selected after comparing against linear regression, decision trees, and random forests during experimentation.

How the prediction is built

1

Sensor selection

13 of the 21 raw sensors were kept — the rest were flat or near-constant across the fleet and carried no degradation signal.

2

Rolling window features

For each selected sensor: a 5-cycle and 10-cycle rolling mean (smoothed level), a 10-cycle rolling linear-fit slope (trend direction and speed), and for 5 key sensors a 10-cycle rolling standard deviation (volatility as engines wear). 58 features total per cycle.

3

RUL capping at 125 cycles

Early in life, engines are stable and RUL is only weakly related to sensor readings — a model that tries to distinguish "300 cycles left" from "280" just chases noise. Capping the training label at 125 cycles concentrates learning capacity on the degradation region, where sensors actually carry signal.

4

Training & evaluation

XGBoost was validated on a held-out split of engines, then evaluated once against NASA's official FD001 test set and true-RUL labels — the numbers below are that official, held-out result.
